# English Coach – phone app

This is the Flutter app. For how to set it up and run it on your phone, see
[the main README](../README.md#run-the-phone-app-on-an-android-phone).

Quick version (once Flutter is installed and the backend is running):

1. Put your laptop's IP address in `lib/config.dart`.
2. Run `flutter pub get`, then `flutter run`.
